# Shared Catalog, private Applications

Friends applying to master's programmes overlap heavily, so Programmes and Scholarships live in one Catalog every member can see and add to, saving re-entry and surfacing options people hadn't found. Each person's Applications (Stage, Checklist progress) stay private to them, so nobody's rejections or choices are on display.

## Considered Options

- Fully separate trackers per person: no shared data, everyone re-types the same Programmes.
- Everything visible to the group: simplest sharing, but exposes outcomes people may not want seen.
