# Checklists follow the Catalog live

An Application's Checklist is derived from the current Requirements of its Programme or Scholarship rather than copied when the Application starts: a Requirement added to the Catalog appears unticked on every existing Checklist, and a removed one disappears. Fixing Catalog mistakes for everyone is a main reason to share the Catalog, and a snapshot would leave earlier starters with the stale version. Anything specific to one Member goes in a Personal item instead.

## Consequences

- A Member's tick on a Requirement is lost if that Requirement is deleted from the Catalog.
